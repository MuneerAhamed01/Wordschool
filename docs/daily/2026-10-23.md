## CW-005 — Remote Config

### Problem
Crossword tunables (hint penalties, reveals, XP curve, autosave interval, min build) need to change without an app release.

### Solution
Added `firebase_remote_config` (^6.7.0, needed for Remote Config itself). `AppRemoteConfig` (abstract) + `FirebaseAppRemoteConfig` expose typed getters over the five card keys with in-app defaults. `initialize()` sets defaults and activates the last fetched values, then fetches in the background (1 h minimum interval), so startup never waits on the network and works offline; new values apply on the next launch. JSON values are parsed by pure `HintPenalties.parse` / `XpLevelFormula.parse`, which fall back to defaults on bad input. Registered in `di.dart` before other features.

**Files:** `lib/core/remote_config/app_remote_config.dart`, `lib/di.dart`, `pubspec.yaml`, `test/core/remote_config/app_remote_config_test.dart`

## CW-006 — App shell: bottom navigation + routes

### Problem
The app had two flat routes (`/auth`, `/game`) with no bottom bar. The signed-in check only ran at startup, so a sign-out during a session didn't send the user back to `/auth`. DEC-007 (accepted) makes Play the start screen, with the daily word game as a card on it.

### Solution
`StatefulShellRoute.indexedStack` with four branches: Play `/home`, Revise `/revise`, Ranks `/ranks`, Profile `/profile`. Each tab keeps its own navigator and state. `AppShell` + `AppBottomNav` follow the prototype nav (76 high, `accent.glow` active icon). On Android, back from another tab goes to Play first, then leaves the app; tapping the active tab returns it to its first page. `/game` stays a top-level route pushed from the Play card, so it opens full screen and back returns to Play. Auth is now a router `redirect` (pure `authRedirect`, unit tested) that re-runs on `FirebaseAuth.authStateChanges()` through `GoRouterRefreshStream`. After sign-in, the app goes to `/home`. Revise/Ranks/Profile are `PlaceholderTab`s; Crossword Home (CW-044) replaces the Play placeholder. Added nav colours to `MyColors` (`navBarBackground`, `gameBorderSubtle`, `navInactive`) from the tokens. No new packages.

**Files:** `lib/core/routes/app_router.dart`, `lib/core/routes/router_refresh.dart`, `lib/main.dart`, `lib/shared/presentations/widgets/{app_shell,app_bottom_nav,placeholder_tab}.dart`, `lib/features/{home,revise,ranks,profile}/presentation/pages/*_page.dart`, `lib/features/auth/presentation/pages/auth_page.dart`, `lib/config/themes/colors.dart`, `test/core/routes/app_router_test.dart`, `test/shared/presentations/widgets/app_shell_test.dart`
