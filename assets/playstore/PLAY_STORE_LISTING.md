## In-app products (when monetization is enabled)

Configure in Play Console → Monetize → Products only when `IS_MONIT_PURCH=true`:

| Product | Type | Description (store-facing) |
| ------- | ---- | -------------------------- |
| Remove Ads | One-time | Hide banner and interstitial ads |
| Hint Pack (5) | Consumable | Five extra letter reveals in detective mode |
| Detective Pro | Subscription | Ad-free experience plus unlimited hints |

At launch with monetization disabled, skip product setup and declare **No ads** and **No in-app purchases**.

## ASO keyword strategy (Play Store)

Unlike the App Store, Google Play has no dedicated keyword field. ASO comes from:

1. **App title** — highest weight; keep brand + primary keyword
2. **Short description** — second highest; front-load keywords naturally
3. **Full description** — repeat key terms 3–5 times without stuffing: *word puzzle*, *daily*, *detective*, *mystery*, *streak*, *leaderboard*, *5-letter*, *brain*
4. **Tags** — category signals for recommendations
5. **Reviews** — encourage users to mention "word puzzle" and "detective" organically

### High-value search terms to weave into copy

- daily word puzzle
- 5 letter word game
- word guess game
- detective mystery game
- brain training puzzle
- word game with streak
- mystery word puzzle

## Post-launch ASO tips

1. **Custom store listings** — create a detective-themed listing for ads targeting mystery gamers.
2. **A/B test** short description and icon in Play Console experiments.
3. **Reply to reviews** mentioning both game modes — helps keyword relevance.
4. **Update "What's new"** with each release; Google favors recently updated apps.
5. **Localized listings** — add Hindi, Spanish, or French once you see geographic download data.
